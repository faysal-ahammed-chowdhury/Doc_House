## 📝 Project Description
**Doc_House** is a web-based Doctor Appointment Management System that simplifies the appointment process for patients, doctors, and administrators.  
The system enables patients to book appointments, doctors to manage sessions and appointments, and admins to control users, specializations, and overall system data.

---

## 🎯 Objectives
- Simplify doctor appointment booking  
- Efficiently manage doctor schedules and sessions  
- Provide role-based access (Doctor, Patient, Admin)  
- Ensure proper session and time-slot management  

---

## 👤 User Roles & Features

### 🧑‍⚕️ Doctor
- Login / Logout / Change Password / Forgot Password  
- View and update profile (email not editable) 
- Create sessions (start time, end time, slot duration)  
- View upcoming and past sessions  
- Delete upcoming sessions if needed  
- View appointment requests by session  
- Accept or reject appointments  
- View and filter all appointments  

---

### 🧑‍💻 Patient
- Register, login, and logout  
- Change password / Forgot password  
- View and update profile (email not editable)  
- Search doctors by name or specialization  
- View doctor profiles  
- Book appointments based on available time slots  
- View and filter appointment history  

---

### 🛠️ Admin
- Login / Logout / Change Password / Forgot Password  
- View and update profile (email not editable)  
- Manage doctor accounts (add, update, delete, view)  
- Manage patient accounts
- Manage all appointments  
- Manage specializations  
- View system statistics  
- Manage other admins (cannot delete self)  

---

## 🗂️ Technologies Used

## 🚀 How to Run the Project
1. Install **XAMPP** on your system and **Git (optional)** if you want to clone the repository.  
2. Copy the project folder **Doc_House** into your XAMPP `htdocs` directory, e.g.: `C:\xampp\htdocs\Doc_House` Or, if you have Git installed, you can clone the repository directly: `git clone https://github.com/faysal-ahammed-chowdhury/Doc_House.git`
3. Start **Apache** and **MySQL** from the XAMPP control panel.  
4. Open **phpMyAdmin** in your browser (`http://localhost/phpmyadmin`) and import the database file provided in the project folder.  
5. Open your browser and visit: `http://localhost/Doc_House`
